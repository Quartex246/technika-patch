# TechnikaPatch

## What is this

A patch to bypass hardware dog detection while running DJMAX TECHNIKA 1

This patch is tested on **International Ver.4** in Windows 11 26H2. It is unknown if the patch works on Korean Edition.

This patch is only able to activate the game. Platinum Crew, card reader and Internet function are not available from this patch.

This repository is only available for downloading patch. Game file will not be released.

This repository will not receive any updates in the future. Issues and PR will not be accepted. Please create your own fork if you want any other functions

**NOTICE:** This patch is not related to NEOWIZ Corporation, PENTAVISION Entertainment nor Rocky Studio. It is a pet project as a training to use AI vibe coding, and the patch will not take any charges to download.



## How to use

Copy the content of this repository to your game folder, and double click `Start-Technika.exe`. Please ensure that patcher folder is also in the game folder

The game is activated in FREE PLAY mode by default. If you want to insert coins (which you need to prepare a token machine by yourself), change `freePlay` status in `patcher\game-settings.json` to `false`
